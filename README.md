# Phishing Awareness QR Demo

This repository hosts a simple webpage used in cybersecurity awareness training.  
When scanned via QR code, the page displays basic browser metadata to simulate how attackers exploit trust.

## How to Use
1. Scan the QR code provided during training.
2. The page will display your browser and device details (from public metadata).
3. A training message will reveal that this was a simulation.

## Purpose
This demo is designed to raise awareness about:
- The risks of blindly trusting QR codes.
- How attackers can exploit device/browser metadata.
- The importance of verifying third-party links before engaging.

⚠️ **Disclaimer:**  
This demo does not collect, store, or transmit personal data.  
It is for *training purposes only* to illustrate phishing and third-party risk awareness.
